# TaxTrace Documentation History

This directory preserves earlier engineering records and specifications so the repository has a clear distinction between **current implementation documentation** and **historical planning/audit material**.

## Categories

- `audits/` — superseded implementation audits and status assessments.
- `specifications/` — original product, architecture, API, data, UI, security, roadmap, and implementation specifications.
- `milestones/` remains outside history because it records the current pilot baseline.

## Important status rule

Several historical documents were written before the backend and frontend were implemented. They may state that TaxTrace is pre-build or not implemented. Those statements are historical and should not be used as the current repository status.

The current status is defined by the root README, active documentation under `docs/`, the current codebase, migrations, tests, and the latest milestone evidence.

No historical engineering record is discarded merely because it became stale.
