## Reference specifications

The repository's original product and engineering specifications remain useful as design references. They should not override the current implementation status.

When a specification and implementation disagree, update the specification/status documentation and use tests and code as the source of truth.

## Status vocabulary

- **Implemented** — present in the repository.
- **Recorded verification** — backed by an existing milestone/audit result.
- **Pilot-ready** — suitable for controlled pilot under the documented limitations.
- **Pending** — required before production use.
- **Deferred** — intentionally postponed.
